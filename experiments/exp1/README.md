# Эксперимент 1: Двусторонний аукцион с AlphaRank анализом

## Описание

Этот эксперимент реализует турнирную систему для нейросетевых агентов в двустороннем аукционе с дискретными ставками и анализом эволюции стационарного распределения на основе AlphaRank.

## Цель

Исследовать поведение нейросетевых агентов в двустороннем аукционе:
1. Создать нейросетевых агентов с дискретными ставками (0-10)
2. Обучить агентов в парных аукционах (покупатель-продавец)
3. Построить матрицу переходов на основе средних выплат
4. Вычислить AlphaRank и анализировать корреляцию с фактическими наградами
5. Визуализировать эволюцию стратегий и частоту сделок

### Запуск отдельных аукционов

```python
from auction_tournament import AuctionTournament

# Аукцион 3x3 (покупатели x продавцы)
tournament = AuctionTournament(
    n_buyers=3,
    n_sellers=3,
    n_actions=11,  # Ставки 0-10
    auctions_per_pair=100
)
tournament.run_evolution(rounds=20)
tournament.plot_evolution()
tournament.save_results()
```

## Механика аукциона

### Агенты
- **Покупатели**: имеют ценность (value) товара
- **Продавцы**: имеют стоимость (cost) производства
- **Ставки**: дискретные значения от 0 до N (N=10)

### Правила сделки
- Если `ставка_покупателя >= ставка_продавца`:
  - Сделка состоялась по цене = (ставка_покупателя + ставка_продавца) / 2
  - Покупатель: reward = value - price
  - Продавец: reward = price - cost
- Иначе: reward = 0 для обоих

## Параметры

- `n_buyers`: Количество покупателей
- `n_sellers`: Количество продавцов
- `n_actions`: Количество возможных ставок (0 до n_actions-1)
- `auctions_per_pair`: Количество аукционов между каждой парой
- `lr`: Learning rate для нейросети (по умолчанию 0.001)
- `rounds`: Количество раундов эволюции

## Результаты

Аукционная система сохраняет:
- JSON файл с полной историей аукционов
- Графики (6 подграфиков):
  - Эволюция стационарного распределения
  - Эволюция средних наград
  - Частота сделок по раундам
  - Корреляция между AlphaRank и наградами
  - Финальные стратегии покупателей (heatmap)
  - Финальные стратегии продавцов (heatmap)

## Алгоритм аукционной системы

1. **Парные аукционы**: Каждый покупатель участвует в аукционах с каждым продавцом
2. **Обучение REINFORCE**: Агенты обновляют стратегии на основе полученных наград
3. **Матрица выплат**: Строится на основе средних наград в парных аукционах
4. **AlphaRank**: Вычисление стационарного распределения
5. **Анализ**: Корреляция, частота сделок, эволюция стратегий
