# Визуализации экспериментов

В этой папке сохраняются графики и диаграммы результатов экспериментов.

## Типы визуализаций

### Турнирные эксперименты
- `prisoners_dilemma_evolution_YYYYMMDD_HHMMSS.png` - Эволюция в дилемме заключенного
- `stag_hunt_evolution_YYYYMMDD_HHMMSS.png` - Эволюция в охоте на оленя
- `large_tournament_evolution_YYYYMMDD_HHMMSS.png` - Большой турнир

### Содержание графиков

Каждая визуализация содержит 4 подграфика:

1. **Эволюция стационарного распределения** - как меняется вероятность каждого агента в AlphaRank
2. **Эволюция средних наград** - как меняются средние награды агентов по раундам
3. **Корреляция** - связь между стационарным распределением и наградами
4. **Финальное сравнение** - сопоставление финальных значений

## Интерпретация

- **Высокая корреляция** (близко к 1) означает, что агенты с высокими наградами действительно доминируют в стационарном распределении
- **Низкая корреляция** (близко к 0) может указывать на нестабильность системы или равновесие
- **Отрицательная корреляция** (меньше 0) указывает на парадоксальную ситуацию
