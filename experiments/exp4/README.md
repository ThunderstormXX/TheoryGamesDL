# Эксперимент 4 — Непрерывные действия (дискретизация), Softmax-SARSA

В этом эксперименте расширяем бинарные игры до непрерывных действий a,b ∈ [0,1],
с дискретизацией на n подотрезков (n+1 точек). Вознаграждение:

r * a * b + p * (1 - a) * b + q * a * (1 - b) + s * (1 - a) * (1 - b)

Параметры r,p,q,s соответственно соответствуют матрице выплат дилеммы (DC, DD, CC, CD и т.п.).
Мы будем использовать Softmax-политику с температурой 1/beta и обновление SARSA с параметрами alpha, gamma.

## Состав
- `continuous_game.py` — среда двух игроков с дискретизацией действий и заданной функцией вознаграждения.
- `softmax_sarsa_agent.py` — агент SARSA с softmax-политикой (настроечные beta, gamma).
- `viz.py` — построение heatmap/гистограмм распределения действий во времени.
- `run_experiment.py` — скрипт запуска эксперимента и построения теплокарт.
- `notebooks/results.ipynb` — ноутбук с примерами запусков.

## Запуск
```bash
python -m experiments.exp4.run_experiment --r 5 --p 0 --q 10 --s 1 --n 20 --steps 2000 --alpha 0.1 --gamma 0.95 --beta 5.0
```

## Зависимости
Используются numpy, matplotlib, tqdm.
