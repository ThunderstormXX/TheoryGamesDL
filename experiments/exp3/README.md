# Эксперимент 3 — Бинарные игры с простыми агентами

В этом эксперименте собраны:

- Простой умный агент на базе Q-обновлений (`SmartAgent`) и фиксированные боты (`SimpleBot`) — файл `bots.py`.
- Универсальная бинарная среда для N игроков с тензорными выплатами и фабрика стандартных игр — файл `environment.py`.
- Утилиты визуализации — файл `viz_utils.py`.
- Скрипт `run_experiment.py` запускает основные сценарии из ноутбука.
- Ноутбук с результатами — `notebooks/results.ipynb`.

## Как запустить

- Сценарии как в ноутбуке:

```bash
python -m experiments.exp3.run_experiment
```

- Открыть ноутбук:

`experiments/exp3/notebooks/results.ipynb`

## Зависимости

Используются зависимости корневого проекта (`numpy`, `matplotlib`, `tqdm` по желанию). Убедитесь, что установлено из `requirements.txt` или `pyproject.toml`.

## Примечания

- В игре кодировка действий: 0 = сотрудничать, 1 = предать.
- Для повторяемости можно зафиксировать сиды в начале скриптов.
