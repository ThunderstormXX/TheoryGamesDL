# Эксперимент exp2: Q-learning для рынка двух продавцов

## Описание

Этот эксперимент моделирует **дуополию Бертрана с дифференцированными продуктами**, где два продавца конкурируют по ценам на частично взаимозаменяемые товары. Агенты используют **Q-learning с больцмановским выбором действий** для обучения оптимальной ценовой стратегии.

## Математическая модель

### Функция спроса

Для продавца \(i\) при установленной цене \(p_i\) и цене конкурента \(p_j\):

$$q_i = 1 - p_i + \eta p_j$$

где:
- \(q_i\) — объем спроса на товар продавца \(i\)
- \(\eta \in (0, 1)\) — параметр перекрестной эластичности (степень замещаемости товаров)

### Функция прибыли

$$\pi_i(p_i, p_j) = (p_i - c) \cdot (1 - p_i + \eta p_j)$$

где:
- \(c\) — себестоимость продукта
- \(\pi_i\) — прибыль продавца \(i\)

### Равновесие Нэша

Для симметричного случая (одинаковые \(c\) и \(\eta\)) равновесная цена:

$$p^* = \frac{1 + c}{2 - \eta}$$

## Алгоритм обучения

### Q-learning

Каждый агент обновляет свою Q-функцию по правилу:

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

где:
- \(\alpha\) — скорость обучения
- \(\gamma\) — коэффициент дисконтирования
- \(r\) — полученная награда (прибыль)

### Больцмановский выбор действий

Вероятность выбора цены определяется через softmax:

$$\pi(p) = \frac{\exp(\beta \cdot Q(p))}{\sum_{p'} \exp(\beta \cdot Q(p'))}$$

где \(\beta\) — параметр обратной температуры (контролирует разведку vs эксплуатацию).

## Использование

### Базовый эксперимент

```bash
cd experiments/exp2
python run_experiment.py
```

Это запустит три сценария:
1. **Симметричные продавцы** — оба с одинаковыми параметрами
2. **Асимметричные продавцы** — разная себестоимость
3. **Сравнение эластичности** — влияние параметра \(\eta\)

### Визуализация

```bash
python visualize.py
```

Создает графики:
- Динамика цен во времени
- Динамика прибыли
- Сходимость к равновесию
- Распределение вероятностей в политике
- Q-функции агентов
- Совместное распределение цен (heatmap)

gamma = 0.9      # Дисконтирование

## Ожидаемые результаты

При правильной настройке параметров:
- Агенты должны сходиться к равновесию Нэша (или близко к нему)
- Цены должны стабилизироваться после периода обучения
- При высокой эластичности (\(\eta \to 1\)) цены ближе к себестоимости (конкуренция)
- При низкой эластичности (\(\eta \to 0\)) цены выше (меньше конкуренции)

## Интерпретация параметров

### Эластичность замещения (\(\eta\))

- **\(\eta = 0\)**: Товары независимы (монополии)
- **\(\eta = 0.5\)**: Умеренная замещаемость
- **\(\eta = 0.9\)**: Почти совершенные заменители (жесткая конкуренция)

### Температура (\(\beta\))

- **\(\beta \to 0\)**: Случайный выбор (высокая разведка)
- **\(\beta = 3.0\)**: Баланс разведки и эксплуатации
- **\(\beta \to \infty\)**: Жадный выбор (только эксплуатация)
