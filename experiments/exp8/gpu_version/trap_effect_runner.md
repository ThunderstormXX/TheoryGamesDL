# Запуск эксперимента Trap Effect

Инструкция по запуску эксперимента для исследования динамики "ловушек" (состояний с локальной асимметрией кооперации) в 2-х и 3-х агентных системах.

### 1. Подготовка окружения
Убедитесь, что вы находитесь в корне проекта [TheoryGamesDL](TheoryGamesDL) и активировали виртуальное окружение:

```bash
cd /Users/macbook/Documents/learning/rl-projects/TheoryGamesDL
source ../.venv/bin/activate
```

### 2. Запуск основного скрипта
Запустите файл [trap_effect_experiment.py](experiments/exp8/gpu_version/trap_effect_experiment.py). Скрипт проведет симуляцию для топологий: `Edge` (2 агента), `Triangle` (3 агента) и `Star` (3 агента).

```bash
python experiments/exp8/gpu_version/trap_effect_experiment.py
```

### 3. Алгоритм работы:
1.  **Симуляция**: Запускается батч из 100 независимых репликаций для каждой топологии.
2.  **Детекция ловушек (Neighbor-Gap)**: Состояние считается "ловушкой", если вероятность кооперации одного агента хотя бы на 0.1 выше средней вероятности его соседей ($p_i - \bar{p}_{nbs} \ge 0.1$).
3.  **Генерация графиков**: Результаты сохраняются в `experiments/exp8/gpu_version/results/`:
    *   `p_combined.png`: Вероятности $p(C)$ всех агентов с выделением зон ловушек (серая заливка).
    *   `delta_q_combined.png`: Значения $\Delta Q = Q(C) - Q(D)$ для всех агентов на одном графике.
    *   `volatility_analysis.png`: Анализ волатильности стратегий внутри и вне ловушек.

### 4. Ключевые параметры
Параметры можно изменить в начале [trap_effect_experiment.py](experiments/exp8/gpu_version/trap_effect_experiment.py):

*   `BENEFIT = 2.0`, `COST = 1.0`: Параметры игры (выигрыш/затраты).
*   `TRAP_NEIGHBOR_GAP = 0.1`: Порог асимметрии для фиксации ловушки.
*   `N_REPS = 100`: Количество параллельных симуляций.

### 5. Метрики в логах
*   `trap_fraction_any_rep`: Доля симуляций, в которых возникла хотя бы одна ловушка.
*   `avg_trap_duration`: Средняя длительность состояния асимметрии.
*   `p_center` / `p_leaves`: (Для `StarGraph`) Позволяет сравнить поведение центрального агента и периферийных.
